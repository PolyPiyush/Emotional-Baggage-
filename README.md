## 🛡️ Anti-Distraction Enforcement System

KINETIC features an in-app active distraction simulation system:
1. **App Interception**: Simulates native blocking of TikTok, Instagram, YouTube Shorts, X (Twitter), and Reddit.
2. **Mentor Intervention**: Triggers custom screen takeovers, warning audio flashes, and character dialogues.
3. **The Penalty Engine**:
   - **Cool Brother**: Gives 2 chances with gentle admonitions.
   - **Enforcer Mom / Strict Father**: Instant focus lockdown with heavy KP deductions.
   - **Steven He**: Triggers full-screen shaking `EMOTIONAL DAMAGE! 🩴` alerts reminding you that cousin Timmy is already running a Fortune 500 company.

## 🤖 Gemini AI Mentor Intelligence

Each mentor features deep conversational intelligence powered by Google's Gemini Models via server-side proxy routes:

- **Model Hierarchy**:
  - `gemini-3.1-pro-preview` for deep personalized goal breakdown and high-thinking strategy.
  - `gemini-3.5-flash` for high-throughput, context-rich multi-turn mentor persona chats.
  - `gemini-3.1-flash-lite` for instantaneous low-latency encouragement and smart task generation.
- **Safety & Architecture**: Express backend (`server.ts`) securely holds `GEMINI_API_KEY`, injecting distinct persona system prompts per mentor and exposing `/api/mentor-chat` and `/api/breakdown-task`.

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js** >= 18.0.0
- **npm** or **yarn**

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/your-username/kinetic-dojo.git

# Navigate into the project directory
cd kinetic-dojo

# Install dependencies
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory:
```env
# Optional: Provide Google Gemini API Key for dynamic AI chat buddy
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to enter the Dōjō.

### 5. Build for Production
```bash
npm run build
npm start
```
